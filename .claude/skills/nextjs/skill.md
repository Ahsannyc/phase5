# Next.js Development Skill

## Purpose
This skill provides expertise in developing applications using Next.js, a popular React-based framework for building production-ready web applications.

## Capabilities
- Create and configure Next.js applications
- Implement page routing and API routes
- Handle server-side rendering (SSR) and static site generation (SSG)
- Manage data fetching with getStaticProps, getStaticPaths, and getServerSideProps
- Implement client-side navigation with Next.js router
- Configure Next.js with custom webpack and babel settings
- Handle image optimization and asset management
- Implement SEO best practices
- Set up dynamic imports and code splitting
- Work with Next.js middleware and edge functions

## Best Practices
- Follow Next.js file-based routing conventions
- Use appropriate data fetching strategies based on use case
- Leverage built-in image optimization
- Implement proper error handling with custom error pages
- Use environment variables securely
- Apply performance optimization techniques
- Follow accessibility guidelines

## Common Commands
- `npx create-next-app` - Initialize a new Next.js project
- `npm run dev` - Start development server
- `npm run build` - Build the application for production
- `npm run start` - Start the production server
