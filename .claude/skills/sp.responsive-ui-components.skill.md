# Responsive UI Components Skill

Name: Responsive UI Components

Instructions:
Reusable Tailwind + TypeScript components for Todo UI

Responsibilities:
- Create TaskCard (title, desc, checkbox, edit/delete icons)
- Create TaskForm (title input, description textarea, submit)
- Create Modal (for add/edit, glassmorphism style)
- Create EmptyState (message + add button)
- Use AI-themed colors (cyan, purple, slate dark base)

Strict rules:
- Server components by default
- Client only for interactivity
- Tailwind classes only – no custom CSS
- Responsive: mobile stack → desktop grid
- Animated checkbox & hover effects

Current project: Phase 2 – beautiful, modern Todo interface

## Implementation Steps

1. Create reusable UI components in `/frontend/src/components/ui/`
2. Implement TaskCard component with title, description, checkbox, and edit/delete icons
3. Create TaskForm with title input, description textarea, and submit functionality
4. Build Modal component with glassmorphism styling for add/edit operations
5. Develop EmptyState component with message and add button
6. Apply AI-themed color palette (cyan, purple, slate dark base)
7. Ensure components are server-first with client-side interactivity only where needed
8. Implement responsive design (mobile stack to desktop grid)
9. Add animations for checkbox and hover effects
10. Use Tailwind exclusively without custom CSS

## Execution

This skill will coordinate with the Frontend Engineer agent to implement the required functionality.
