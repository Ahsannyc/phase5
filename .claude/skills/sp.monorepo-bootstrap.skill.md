# Monorepo Bootstrap Skill

Name: Monorepo Bootstrap

Instructions:
Bootstrap full monorepo structure for Phase 2 Todo app

Responsibilities:
- Create folders: frontend, backend, specs, skills, tests
- Initialize Next.js (App Router + TypeScript + Tailwind) in /frontend
- Initialize FastAPI + Poetry in /backend
- Create .env.example with DATABASE_URL & BETTER_AUTH_SECRET
- Add basic docker-compose.yml template

Strict rules:
- Use create-next-app command with correct flags
- Do not install extra UI libraries
- Keep structure monorepo-friendly for later phases

Current project: Phase 2 full-stack Todo (Next.js + FastAPI + Neon)

## Implementation Steps

1. Create the required directory structure (frontend, backend, specs, skills, tests)
2. Initialize Next.js project in the frontend directory with App Router, TypeScript, and Tailwind
3. Set up FastAPI project in the backend directory with Poetry
4. Create .env.example file with required environment variables
5. Generate docker-compose.yml template for container orchestration
6. Verify all components are properly configured for monorepo structure
