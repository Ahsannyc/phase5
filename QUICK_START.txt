================================================================================
STEP 3: INSTALL DEPENDENCIES
================================================================================

Terminal 1 - Install Backend:
  cd backend
  pip install -r requirements.txt

Terminal 2 - Install Frontend:
  cd frontend
  npm install

================================================================================
STEP 4: RUN DATABASE MIGRATIONS
================================================================================

Terminal - Run Migrations:
  cd backend
  alembic upgrade head

This creates the conversations and messages tables.

================================================================================
STEP 5: START THE SERVERS
================================================================================

Terminal 1 - Start Backend:
  cd backend
  uvicorn app.main:app --reload --port 8000

You should see: "Uvicorn running on http://127.0.0.1:8000"

Terminal 2 - Start Frontend:
  cd frontend
  npm run dev

You should see: "localhost:3000"

================================================================================
TROUBLESHOOTING
================================================================================

Backend won't start?
  - Check: COHERE_API_KEY is set in backend/.env
  - Check: DATABASE_URL is correct
  - Try: pip install -r requirements.txt again

Frontend won't start?
  - Try: rm -rf node_modules && npm install
  - Check: NODE_VERSION >= 18

Chat not responding?
  - Check backend logs for errors
  - Verify JWT token is being sent
  - Check database migration ran: alembic upgrade head

Can't reach backend from frontend?
  - Check: NEXT_PUBLIC_BACKEND_URL=http://localhost:8000 in frontend/.env

================================================================================
WHAT'S ACTUALLY HAPPENING
================================================================================

When you type "Add task buy groceries":

1. Frontend sends to: POST http://localhost:8000/api/chat/send
2. Backend AgentRunner recognizes intent: "add_task"
3. Calls TodoTools.add_task() with your user_id
4. Creates task in PostgreSQL database
5. Returns formatted response: "✅ Task 'buy groceries' created!"
6. Saves conversation to database
7. Returns to frontend
8. Displays in chat UI

================================================================================
API ENDPOINTS (if testing manually)
================================================================================

Send Message:
  curl -X POST http://localhost:8000/api/chat/send \
    -H "Authorization: Bearer YOUR_JWT_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"content": "Add task test", "conversation_id": null}'

List Conversations:
  curl -X GET http://localhost:8000/api/chat/conversations \
    -H "Authorization: Bearer YOUR_JWT_TOKEN"

Get Messages:
  curl -X GET http://localhost:8000/api/chat/conversations/1/messages \
    -H "Authorization: Bearer YOUR_JWT_TOKEN"
